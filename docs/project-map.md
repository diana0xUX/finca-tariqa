## style.css

**Agents must know before editing:**
- This is the only shared CSS file. All pages `<link>` to it.
- It contains: CSS variables (`:root`), reset, typography, nav, buttons, footer, `.section`, `.hero`, utility classes, responsive breakpoints.
- It does NOT contain page-specific styles — those live in `<style>` blocks in each HTML file.
- Never move page-specific styles here. Never put shared styles in individual pages.
- The nav, footer, buttons, and typography must be consistent across all pages — changes here affect everything.

**Key breakpoints:**
- 900px — grid-3 collapses to 1 col
- 700px — grid-2 collapses, mobile nav activates
- 480px — grid-4 collapses, stat-strip stacks

---

## blog/

**Agents must know before editing:**
- All links within `blog/*.html` use `../` prefix (e.g., `../style.css`, `../index.html`)
- `blog/index.html` is manually maintained — the CMS function `_regenerate_index()` can regenerate it, but doing so may drift from the current editorial list style. Edit directly.
- `blog/heat-resilience-report.html` has a custom audio player with a 59-entry `TIMING` array. Do not edit without understanding the `data-para` sync mechanism.
- `blog/land-certificates.html` — status unknown. Not in index, not in sitemap. Do not delete without checking with Diana.

---

## images/

**Agents must know before editing:**
- Added August 2026 — this directory did not exist before then
- Images are Midjourney renders, not real farm photographs
- When referencing images in HTML, use relative paths: `src="images/filename.png"` (from root pages) or `src="../images/filename.png"` (from blog subdirectory)
- `glamping-hillside-2.png` exists but is not referenced in HTML — check before assuming it's unused

---

## tokens/ and contracts/

**Agents must know before editing:**
- These directories are disallowed in `robots.txt` — they are not meant for public indexing
- `GroveToken.sol` is a Solidity smart contract for an ERC-721 NFT on Polygon — not deployed to mainnet
- Do not modify these files without understanding the full Grove Token architecture
- Do not link to pages in `tokens/` or `contracts/` from public-facing nav

---

## docs/ and skills/

**Agents must know:**
- These are the shared AI infrastructure directories created August 2026
- They do not affect the live website — they are documentation only
- Update `docs/ai-work-log.md` and `docs/ai-handoff.md` at the end of every significant task
- Skills in `skills/` are not code — they are prompt context documents for AI agents
